# WSM

WSM — незалежний дослідницький проєкт.

Він не починається з Lisp, Rust, готової віртуальної машини,
Boolean-моделі, системи типів чи заздалегідь визначеної математики.

Стартова точка:

()

Жодного змісту `()` не приписується, окрім самої присутності.

Перший дослідницький горизонт — математика:

() → ? → математика

Шлях між ними не визначений заздалегідь.
Кожне введене розрізнення має бути обґрунтоване, а не успадковане.

WSM призначений бути фізично реалізованим на реальному залізі.
Assembly використовується як дослідницький інструмент для розуміння
можливостей і меж машини.

Довгостроковий експериментальний свідок:

() → ... → математика → 2 + 2 = 4 → t

## WSM (English)

WSM is an independent research project.

It does not begin from Lisp, Rust, an existing virtual machine,
a Boolean model, a type system, or a predefined mathematics.

The starting point is `()`. No meaning is assigned to it beyond its
presence.

The first research horizon: `() → ? → mathematics`. The path between
them is not predefined; every introduced distinction must be justified,
not inherited.

WSM is intended to be physically realizable on real hardware. Assembly
is a research instrument for understanding the machine's capabilities
and limits, not a foundation.

Long-term experimental witness: `() → ... → mathematics → 2 + 2 = 4 → t`.
