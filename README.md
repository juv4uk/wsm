# WSM

WSM is an independent research project.

It does not begin from Lisp, Rust, an existing virtual machine,
a Boolean model, a type system, or a predefined mathematics.

The starting point is:

()

No meaning is assigned to () beyond its presence.

The first research horizon is mathematics:

() → ? → mathematics

The path between them is not predefined.
Every introduced distinction must be justified rather than inherited.

WSM is intended to be physically realizable on real hardware.
Assembly is used as a research instrument for understanding the
capabilities and limits of the machine.

Long-term experimental witness:

() → ... → mathematics → 2 + 2 = 4 → t
